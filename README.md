# Chateau Lamotte Prissac

**Website repository for Chateau Lamotte Prissac — Prissac, Indre, France**

This repository serves as the central hub for all planning, content, design assets, and custom code related to the Chateau Lamotte Prissac website, built and hosted on **Wix Studio**.

---

## About the Project

Chateau Lamotte Prissac is a historic 18th-century property in Prissac, Indre, in the Centre-Val de Loire region of France — situated within the Parc Naturel Régional de la Brenne. The château is being restored by **Jill Craft** (civil rights attorney) and **Jim Shannon** (former journalist) of Baton Rouge, Louisiana, and will operate as a luxury vacation rental marketed primarily to American travelers.

Follow the journey on YouTube: [@ouideuxredouxchateau](https://www.youtube.com/@ouideuxredouxchateau)

## Platform

The live website is built and hosted on **Wix Studio**. This repository does not deploy to the site — it is used for:

- Version control of copy, docs, and planning materials
- Storage of design assets
- Collaboration between team members
- Custom code snippets before they are added to Wix
